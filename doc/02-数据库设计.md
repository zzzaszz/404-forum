# 02 · 数据库设计

> 完整建表脚本：`doc/atest.sql`（MySQL 8.0，utf8mb4）。共 14 张表。
> 初始化种子数据（默认板块）：`doc/seed.sql`。

## 表清单

| 表名                  | 说明           | 关键字段                                                                                            |
|---------------------|--------------|-------------------------------------------------------------------------------------------------|
| `User`              | 用户（匿名系统真实主体） | DeviceId(唯一)、Nickname、Status(1正常2封禁)                                                            |
| `UserToken`         | JWT 会话       | AccessToken(唯一)、RefreshToken、ExpireAt                                                           |
| `UserDevice`        | 用户设备         | UserId、DeviceId                                                                                 |
| `UserBehavior`      | 行为埋点（推荐）     | BehaviorType(1浏览2点赞3收藏4评论)、TargetType、TargetId                                                  |
| `Board`             | 社区板块         | Code(唯一)、Name、SortOrder、PostCount、Status(1正常0隐藏)                                                |
| `Post`              | 帖子（核心）       | BoardId、UserId、AnonymousName/Avatar/Color、Title、Content、各计数、HotScore、Status(1正常2审核中3删除)、Deleted |
| `Comment`           | 评论（楼中楼）      | PostId、RootId、ParentId、ReplyUserId、AnonymousName、LikeCount、ReplyCount、Status                    |
| `LikeRecord`        | 点赞记录         | UserId+TargetType+TargetId(唯一)，TargetType(1帖2评)                                                 |
| `FavoriteRecord`    | 收藏记录         | UserId+PostId                                                                                   |
| `Report`            | 举报           | ReportUserId、TargetType、TargetId、Reason、Status(0未处理1已处理)                                        |

| `Tag` / `PostTag`   | 标签及帖子关联      | Tag.Name、PostTag(PostId,TagId)                                                                  |

| `AnonymousIdentity` | 匿名身份映射       | UserId+PostId(唯一)、AnonymousName/Avatar/Color                                                    |

## 命名约定

- 列名：PascalCase（`Id`、`BoardId`、`CreatedAt`）。
- MyBatis 开启 `map-underscore-to-camel-case`，且列名与 Pojo 属性大小写不敏感匹配，故 `BoardId` ↔ `boardid`。
- 时间列：`CreatedAt` 默认 `CURRENT_TIMESTAMP`，`UpdatedAt` `ON UPDATE CURRENT_TIMESTAMP`。
- 逻辑删除：`Post.Deleted`（0/1）；评论/举报用 `Status` 区分。

## 关键索引

- `Post`：`IndexBoardId`、`IndexHotScore`、`IndexCreatedAt`
- `Comment`：`IndexPostId`、`IndexRootId`
- `LikeRecord`：唯一索引 `UkUserTarget(UserId,TargetType,TargetId)` 防重复点赞
- `Board` / `User`：`Code` / `DeviceId` 唯一

## 默认板块（种子）

见 `doc/seed.sql`：random（随便聊聊）、tech（技术交流）、game（游戏讨论）、life（生活分享）、help（求助问答）。前端固定路由与动态
`boardCode` 均对应这些 Code。
