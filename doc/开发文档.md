> 相关文档：`DB相关.md`（完整建表方案） | `匿名社区后端相关分析.md`（后端技术体系） | `index.html`（前端 Demo）

## 一、项目概述

### 1.1 项目简介

一个支持多板块分类的匿名发帖/回复社区平台。用户无需注册登录，可自由选择板块发布匿名帖子，其他用户可对帖子进行匿名回复。包含 Web 管理后台 + 移动端 App。

### 1.2 核心功能

- 板块分类管理（如：情感树洞、技术交流、生活吐槽、匿名表白、求职招聘 等）
- 发帖 / 回复（匿名）
- 帖子按热度 / 时间排序
- 点赞 / 举报
- 敏感词过滤
- Web 端后台管理（板块管理、内容审核、用户封禁）
- 移动端 App（Flutter）

## 六、关键技术点

### 6.1 匿名身份生成

- 每次发帖/回复时服务端随机生成匿名昵称 + 头像 + 颜色
- 同一请求内（同一 IP + 短时间）生成相同匿名身份，保证用户体验一致性
- 使用 `IP + User-Agent` 做 hash 映射到预设昵称池

### 6.2 敏感词过滤

- 加载 `sensitive-words.txt` 到内存（DFA 算法 / Trie 树）
- 发帖/回复时拦截校验，命中则拒绝并提示
- 管理后台支持动态更新敏感词

### 6.3 限流防刷

- 基于 Redis 实现滑动窗口限流
- 单 IP 每分钟发帖上限、回复上限
- 使用 `Interceptor` 或自定义注解 `@RateLimit` 实现

### 6.4 分页与排序

- MyBatis-Plus `Page` 对象实现分页
- 支持排序策略：`latest`（按创建时间）、`hot`（按回复数 + 点赞数加权）

### 6.5 Redis 缓存

| 用途 | Key 格式 | 说明 |
|------|----------|------|
| 板块帖子缓存 | `board:posts:{boardId}` | ZSET，score 为热度值 |
| 限流计数 | `rate:post:{ipHash}` | 滑动窗口 |
| 点赞去重 | `like:{type}:{targetId}` | SET，存 ipHash |
| 热点帖子详情 | `post:detail:{id}` | String，过期 5min |

### 6.6 跨域配置

- Spring Boot `CorsConfig` 允许前端开发服务器跨域
- 生产环境通过 Nginx 反向代理

### 6.7 文件上传

- 帖子可附带图片（截图、表情包等）
- 开发阶段使用本地存储 `uploads/`
- 生产环境接入阿里云 OSS / 腾讯云 COS

## 八、Flutter 移动端技术要点

### 8.1 架构

- MVVM 模式
- `Provider` / `Riverpod` 状态管理
- `Dio` 网络请求封装
- `shared_preferences` 本地缓存

### 8.2 关键页面

- 首页：板块网格列表
- 板块页：帖子列表（下拉刷新、上拉加载）
- 帖子详情：主帖 + 回复列表（嵌套滚动）
- 发帖页：标题 + 内容 + 图片选择
- 个人中心（可选）：浏览历史、我的发帖 基于 IP 标识）

### 8.3 适配

- 适配 iOS 安全区域
- Android Material Design 风格
- 暗黑模式支持
