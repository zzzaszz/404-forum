# 06 · 登录与注册（账号密码）

> 改造说明：原登录基于 `deviceId` 隐式注册/登录，现已改为**账号 + 密码**显式登录与注册。

## 一、数据库变更

`User` 表新增两列（迁移脚本：`doc/migration-account-password.sql`）：

| 列              | 类型           | 说明                          |
|----------------|--------------|-----------------------------|
| `Username`     | varchar(64)  | 登录账号，唯一索引 `UkUsername`      |
| `PasswordHash` | varchar(255) | 密码哈希，格式 `salt:hash`（Base64） |

执行顺序：`doc/atest.sql` 建表 → `doc/migration-account-password.sql` 加列 → `doc/seed.sql` 板块种子。

> 密码不存明文。`PasswordHash` 由后端 `PasswordUtils.encode(明文)` 生成（SHA-256 + 16 字节随机盐）。

## 二、接口

### 2.1 注册 `POST /api/auth/register`

请求体：

```json
{
  "username": "demo",
  "password": "123456",
  "nickname": "可选昵称",
  "deviceId": "可选设备标识"
}
```

校验规则：

- `username`：3-32 位字母/数字/下划线，唯一
- `password`：6-32 位
- `nickname`：选填，留空则系统随机生成
- 同 IP 每天最多注册 5 个账号（Redis 限流）

成功响应（注册成功后直接签发 token，无需再次登录）：

```json
{
  "code": 200,
  "msg": null,
  "data": {
    "accessToken": "...",
    "refreshToken": "...",
    "token": "...",
    "userId": 329905409110446201,
    "nickname": "匿名小猫12345",
    "avatar": ""
  }
}
```

失败响应（HTTP 200，业务码 500）：

```json
{
  "code": 500,
  "msg": "该账号已被注册",
  "data": null
}
```

### 2.2 登录 `POST /api/auth/login`

请求体：

```json
{
  "username": "demo",
  "password": "123456",
  "deviceId": "可选"
}
```

逻辑：

- 按 `username` 查用户，`PasswordUtils.matches(明文, PasswordHash)` 校验
- 账号不存在或密码错误统一提示「账号或密码错误」（防枚举）
- 账号被封禁（`Status=2`）提示「账号已被封禁」
- 同 IP 每分钟最多登录 10 次

成功响应与注册一致。失败响应同上（如 `{ "msg": "账号或密码错误" }`）。

### 2.3 刷新 / 登出

- `POST /api/auth/refresh`：请求体 `{ refreshToken }`，返回新的 `accessToken`。
- `POST /api/auth/logout`：请求体 `{ accessToken, refreshToken }`，清除 Redis 中的 token。

以上接口均由 `JwtFilter` 放行（无需 token）。

## 三、密码安全

`zzz.service.forum.utils.PasswordUtils`：

| 方法                                     | 说明                               |
|----------------------------------------|----------------------------------|
| `encode(rawPassword)`                  | 生成随机盐 → SHA-256 → 返回 `salt:hash` |
| `matches(rawPassword, storedPassword)` | 拆盐重算哈希比对                         |

- 不引入额外依赖，使用 JDK 内置 `MessageDigest` / `SecureRandom`。
- 后续若引入 `spring-security`，可平滑替换为 `BCryptPasswordEncoder`。

## 四、前端

- `web/src/views/Login.vue`：账号 + 密码表单，支持「登录 / 注册」切换；注册时多出可选昵称字段；密码可显隐切换。
- `web/src/api/index.js`：新增 `register(data)`，`login(data)` 入参改为 `{ username, password }`。
- 登录/注册成功后写入 `token / accessToken / refreshToken / userInfo` 到 `localStorage`，跳转首页。
- 失败时由 `request.js` 拦截器读取 `res.msg` 统一 `ElMessage.error` 提示（如「账号或密码错误」）。

## 五、字段映射

后端 `LoginResponse` → 前端 `localStorage.userInfo`：

| 后端                      | 前端                      |
|-------------------------|-------------------------|
| `token` / `accessToken` | `token` / `accessToken` |
| `refreshToken`          | `refreshToken`          |
| `userId`                | `userInfo.userId`       |
| `nickname`              | `userInfo.nickname`     |
| `avatar`                | `userInfo.avatar`       |
