# 07 · 图片资源需求清单

> 本文档列出 404-Forum 项目所需的全部图片资源，含用途、尺寸、格式、命名与存放路径。
> 设计师 / 美术按本清单产出素材，前端按命名直接引用。

## ✅ 已接入图片（web/public/images/）

| 文件                        | 尺寸        | 用途           | 接入位置                                |
|---------------------------|-----------|--------------|-------------------------------------|
| `favicon.png`             | 799×746   | 浏览器标签图标      | `index.html` `<link rel="icon">`    |
| `favicon2.png`            | 799×746   | 登录页 logo     | `Login.vue` logo-box                |
| `404.png`                 | 1536×1024 | 品牌图（备用 logo） | —                                   |

## 一、总则

| 项    | 约定                                                    |
|------|-------------------------------------------------------|
| 存放目录 | `web/public/images/`（静态资源，构建后原样输出）                    |
| 引用方式 | 绝对路径 `/images/xxx.png`（无需 import）                     |
| 主品牌色 | `#7C3AED`（紫，accent）/ `#1E40AF`（蓝，primary）             |
| 风格   | 扁平、简洁、匿名社区调性；图标优先用 SVG，照片类用 WebP                      |
| 命名   | 全小写 + 中划线，如 `login-bg.png`、`logo.svg`、`avatar-01.png` |
| 透明背景 | logo / icon / 头像统一用透明背景（PNG 或 SVG）                    |

> 若暂无设计稿，可先用占位图，但**文件名与尺寸需与本清单一致**，便于后续无缝替换。

## 二、需求清单

### 1. Favicon 浏览器标签图标

| 字段  | 值                                            |
|-----|----------------------------------------------|
| 用途  | 浏览器标签页、书签图标                                  |
| 文件名 | `favicon.ico`                                |
| 尺寸  | 多尺寸合一：16×16、32×32、48×48                      |
| 格式  | `.ico`（兼容性最佳）；另备 `favicon-32.png`（32×32 PNG） |
| 存放  | `web/public/`（根目录，直接 `/favicon.ico`）         |
| 设计  | 以「404」或论坛 logo 为主体，紫底白字或描边                   |
| 引用  | `web/index.html` 的 `<link rel="icon">`       |

### 2. Logo 标志

| 字段  | 值                                               |
|-----|-------------------------------------------------|
| 用途  | 登录页、侧边栏顶部                                       |
| 文件名 | `logo.svg`（矢量主用）/ `logo.png`（备用，需 @2x）          |
| 尺寸  | SVG 自适应；PNG 提供 64×64 与 128×128 两档               |
| 格式  | SVG（首选）/ PNG（透明）                                |
| 存放  | `web/public/images/`                            |
| 设计  | 含「404」字样或抽象图形，体现匿名/社区属性                         |
| 引用  | `Login.vue` logo-box、`MainLayout.vue` logo-icon |

### 3. 登录页背景图

| 字段  | 值                                                     |
|-----|-------------------------------------------------------|
| 用途  | 登录页全屏背景（当前为 CSS 渐变占位）                                 |
| 文件名 | `login-bg.jpg`（照片类）/ `login-bg.webp`（推荐，体积更小）         |
| 尺寸  | 1920×1080（横屏），另备 750×1624（移动端竖屏，可选）                   |
| 格式  | WebP（首选）/ JPG                                         |
| 存放  | `web/public/images/`                                  |
| 设计  | 低饱和度抽象渐变 / 几何 / 城市夜景，与紫蓝主色协调；不可喧宾夺主，建议叠加 20%-40% 暗色蒙版 |
| 体积  | ≤ 300KB（WebP）                                         |
| 引用  | `Login.vue` `.login-bg`                               |

### 4. 默认用户头像（匿名身份）

## 三、目录结构（建议）

```
web/public/
├── favicon.ico                 # 浏览器标签图标
├── favicon-32.png              # 32×32 PNG 备用
└── images/
    ├── logo.svg                # Logo
    ├── login-bg.webp           # 登录页背景
    ├── avatar-default.png      # 默认头像
    ├── loading.svg             # 加载占位
    ├── og-cover.jpg            # OG 分享图（可选）
    ├── avatars/                # 匿名头像池（12 张）
    │   ├── avatar-01.png
    │   └── ...
    ├── boards/                 # 板块图标（5 个）
    │   ├── board-random.svg
    │   └── ...
    └── empty/                  # 空状态插画
        ├── empty-topics.svg
        ├── empty-search.svg
        └── empty-message.svg
```

## 四、接入说明

1. **favicon**：替换 `web/index.html` 中 `<link rel="icon" href="/vite.svg">` 为 `/favicon.ico`。
2. **logo**：`Login.vue` / `MainLayout.vue` 的 logo-box 由文字「404」改为 `<img src="/images/logo.svg">`。
3. **登录背景**：`Login.vue` `.login-bg` 由 CSS 渐变改为 `background: url(/images/login-bg.webp) center/cover`
   ，并保留半透明蒙版层保证文字可读。
4. **板块图标**：前端板块列表用 `Board.Icon` 字段映射到 `/images/boards/board-{code}.svg`（后端 `Board.Icon` 存 code 或
   URL 均可）。
5. **匿名头像**：若启用图片头像池，后端 `ForumServiceImpl` 的 `AVATAR_POOL` 改为 `avatar-01` ~ `avatar-12`，前端用
   `/images/avatars/${avatar}.png` 渲染。

## 五、优先级

| 优先级   | 资源                     |
|-------|------------------------|
| P0 必需 | favicon、logo、登录背景、默认头像 |
| P1 重要 | 板块图标、匿名头像池             |
| P2 增强 | 空状态插画、加载占位、OG 分享图      |
