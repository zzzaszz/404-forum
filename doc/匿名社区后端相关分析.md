# 二、核心业务技术点

# 1. 匿名体系设计（重点）

匿名 ≠ 不记录用户。

一般会：

| 对用户     | 对系统             |
| ---------- | ------------------ |
| 匿名显示   | 实际有 uid         |
| 昵称随机   | 后端真实身份可追踪 |
| 前台不可见 | 管理员可审计       |

核心实现：

```
user_id -> anonymous_id
```

例如：

```
用户A 在帖子1里 = “树洞猫猫”
用户A 在帖子2里 = “匿名用户”
```

常见方案：

## 局部匿名

同一个帖子保持同一匿名身份：

```
hash(uid + postId)
```

## 全局匿名

每次发言随机：

```
UUID
```
