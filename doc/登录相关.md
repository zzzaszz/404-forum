# 一、整体设计（先讲清架构）

## ✔ 双 Token 模型

```
AccessToken（短期） + RefreshToken（长期 + Redis）
```

| Token        | 作用             | 存储              |
| ------------ | ---------------- | ----------------- |
| AccessToken  | 请求鉴权         | 不存 or Redis可选 |
| RefreshToken | 刷新 AccessToken | Redis             |

------

## ✔ 登录流程

```
1. deviceId → 登录
2. 查User / 注册User
3. 生成 AccessToken + RefreshToken
4. RefreshToken 存 Redis
5. 返回前端
```

# 三、JWT工具类（核心）

```
import io.jsonwebtoken.*;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

public class JwtUtil {

    private static final String SECRET = "anonymous-community-secret";
    private static final long ACCESS_EXPIRE = 1000 * 60 * 30; // 30分钟
    private static final long REFRESH_EXPIRE = 1000L * 60 * 60 * 24 * 30; // 30天

    // 生成AccessToken
    public static String generateAccessToken(Long userId, String deviceId) {
        return createToken(userId, deviceId, ACCESS_EXPIRE);
    }

    // 生成RefreshToken
    public static String generateRefreshToken(Long userId, String deviceId) {
        return createToken(userId, deviceId, REFRESH_EXPIRE);
    }

    private static String createToken(Long userId, String deviceId, long expire) {

        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("deviceId", deviceId);

        return Jwts.builder()
                .setClaims(claims)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + expire))
                .signWith(SignatureAlgorithm.HS256, SECRET)
                .compact();
    }

    // 解析Token
    public static Claims parse(String token) {
        return Jwts.parser()
                .setSigningKey(SECRET)
                .parseClaimsJws(token)
                .getBody();
    }
}
```

# 六、登录Service（核心业务）

```
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;

import java.util.concurrent.TimeUnit;

@Service
public class AuthService {

    private final StringRedisTemplate redisTemplate;
    private final UserMapper userMapper;

    public AuthService(StringRedisTemplate redisTemplate, UserMapper userMapper) {
        this.redisTemplate = redisTemplate;
        this.userMapper = userMapper;
    }

    public LoginResponse login(String deviceId, String ip) {

        // 1. 查用户
        User user = userMapper.selectByDeviceId(deviceId);

        // 2. 不存在则注册
        if (user == null) {
            user = new User();
            user.setDeviceId(deviceId);
            user.setNickname("匿名用户");
            userMapper.insert(user);
        }

        Long userId = user.getId();

        // 3. 生成Token
        String accessToken = JwtUtil.generateAccessToken(userId, deviceId);
        String refreshToken = JwtUtil.generateRefreshToken(userId, deviceId);

        // 4. Redis存RefreshToken
        redisTemplate.opsForValue().set(
                RedisKey.refreshTokenKey(refreshToken),
                String.valueOf(userId),
                30,
                TimeUnit.DAYS
        );

        return new LoginResponse(accessToken, refreshToken, user);
    }
}
```

# 九、JWT鉴权 Filter（核心）

```
import io.jsonwebtoken.Claims;
import org.springframework.web.filter.OncePerRequestFilter;

import javax.servlet.*;
import javax.servlet.http.HttpServletRequest;
import java.io.IOException;

public class JwtFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    javax.servlet.http.HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {

        String token = request.getHeader("Authorization");

        if (token != null && token.startsWith("Bearer ")) {

            token = token.substring(7);

            try {
                Claims claims = JwtUtil.parse(token);

                Long userId = Long.valueOf(claims.get("userId").toString());

                // 放入ThreadLocal
                UserContext.setUserId(userId);

            } catch (Exception e) {
                response.setStatus(401);
                return;
            }
        }

        filterChain.doFilter(request, response);
    }
}
```

# 十一、Refresh Token 刷新接口

```
@PostMapping("/refresh")
public LoginResponse refresh(@RequestBody RefreshRequest req) {

    String key = RedisKey.refreshTokenKey(req.getRefreshToken());

    String userId = redisTemplate.opsForValue().get(key);

    if (userId == null) {
        throw new RuntimeException("RefreshToken expired");
    }

    User user = userMapper.selectById(Long.valueOf(userId));

    String newAccessToken = JwtUtil.generateAccessToken(user.getId(), user.getDeviceId());

    return new LoginResponse(newAccessToken, req.getRefreshToken(), user);
}
```

# 十四、这一套设计的关键点（很重要）

## ✔ 为什么 Redis 存 RefreshToken？

- 可以强制踢人（删 Redis）
- 支持单设备登录
- 支持封号立即失效
- 不依赖 JWT 自身不可控过期

------

## ✔ 为什么 AccessToken 不进 Redis？

- 减少 IO
- 提升性能
- JWT 自带验证能力

------

## ✔ 为什么要双 Token？

| 问题         | 解决              |
| ------------ | ----------------- |
| JWT 不能失效 | RefreshToken 控制 |
| 被盗风险     | AccessToken 短期  |
| 多端登录     | Redis可控         |
