# 04 · 前端对接文档

## 一、请求封装（`web/src/utils/request.js`）

- axios 实例 baseURL：开发环境 `/api`，生产环境 `''`。
- 请求拦截器：自动注入 `Authorization` 头（取 `localStorage.token`）。
- 响应拦截器：`res.code === 200` 直接返回 `res`；`401` 触发 `refreshToken` 刷新后重试；token 失效跳转登录。
- Vite 代理：`/api → http://localhost:10610`，去掉 `/api` 前缀（见 `vite.config.js`）。

> 因此前端 API 函数中 `url` 写**真实后端路径**：登录类写 `/api/auth/xxx`，论坛类写 `/forum/xxx`，通用 CRUD 写
`/{entity}/xxx`。baseURL 的 `/api` 仅作代理标识。

## 二、API 函数清单（`web/src/api/index.js`）

### 通用 CRUD（管理后台）

`getEntity / getPageList / createEntity / updateEntity / deleteEntity / postJson` 等，配合 `BOARD_URL='/board'` 等使用。

### 鉴权

`login(data)` / `register(data)`：入参 `{ username, password, nickname?, deviceId? }`，返回 `LoginResponse`
（token/accessToken/refreshToken/userId/nickname/avatar）。
`logout(accessToken, refreshToken)` / `getUserInfo()` / `updatePassword(data)`

> 登录/注册为账号密码模式，详见 `06-登录注册文档.md`。

## 四、字段映射规范

后端 Pojo 为驼峰小写（如 `anonymousName`、`viewCount`），前端展示统一映射：

```js
function mapTopic(p) {
    return {
        id: p.id,
        title: p.title,
        content: p.content,
        author: p.anonymousName || '匿名用户',
        avatar: p.anonymousAvatar || '',
        color: p.anonymousColor || '#7C3AED',
        views: p.viewCount || 0,
        comments: p.replyCount || 0,
        likes: p.likeCount || 0,
        heat: p.hotScore || 0,
        category: p.boardName || p.boardCode || '',
        boardCode: p.boardCode,
        createTime: p.createdAt,
    }
}
```

## 五、交互约定

- 列表加载：`onMounted` 调用，显示骨架/loading，空态 `el-empty`。
- 发帖/评论：表单校验 → 提交 → 成功提示并刷新列表。
- 点赞/收藏：乐观更新，失败回滚。
- 时间展示：使用 `dayjs` 相对时间或 `YYYY-MM-DD HH:mm`。
